# CEO 简报：竞标 Meta 一代，长虹佳华能不能赢、怎么赢

数据截至 2026-10-10 · 4 家竞标对手 + 长虹佳华 · 先查红线，再比分数；查不到就标「查不到」 · 交互页面可调权重、增减名单、录入新情报

## 结论

**按已证实的信息，店匠领先长虹佳华 4 分（45 vs 41），两家是同一梯队。** 长虹佳华资金有营运资金占用信号、合规未做工商核验，两条红线都是「通过·待确认」。在这 5 家里，长虹佳华排第一的概率约 42%（店匠约 43%），排进前 2 约 75%。对手的减资、诉讼只是未核实线索，不按出局算。两家先后对检查项分值敏感（约 1/4 的给法下长虹佳华在前）。

差距主要来自「客户增量」：长虹佳华的出海客户在公开信息里几乎看不到。**公开产业带布局这一项就能反超，再拿出 2–3 个可核实的出海营销案例能拉开差距。** 概率只在这 5 家之间比较，不包括 Meta 的主观判断、路演表现和名单外的候选人。

## 怎么做

1. **补「客户增量」**：整理出海客户的行业分布和可核实案例；和领拓、龙商签合作意向，路演时展示已锁定的增量客户。
2. **补「增长投入」**：路演给出 90 天启动计划、专职团队规模和首年客户目标；同时用 Google 合作伙伴认证证明「平台认证跑通过一次」。
3. **用好「财务与授信」，同时讲清资金口径**：授信回款体系有公告可查，可以做成给中小卖家的产品；但报表经营现金流连续三年为负、应收 36 亿元，路演资金页要主动给出两种口径和可用于广告授信的额度。
4. **和店匠找互补位**：它补「独立站商家 + 自动化」，我们占它没有的位置，不正面硬拼。

## 需要你拍板的三件事

1. **路演主线**：名额 2 个时走「互补位」，1 个时走「正面赢店匠：资金、合规、授信」。名额数以贵司从 Meta 拿到的信息为准。
2. **是否启动和领拓、龙商的结盟洽谈**。
3. **7 天内补齐内部数据，指定负责人**：产业带布局、可披露案例、可用于广告授信的资金额度。

## 五个关键判断

1. **国企 + 上市是入场券，不是差异化**：现任一代里省广集团国资控股且上市，蓝标、猎豹上市，熊猫新媒隶属上市公司。
2. **返点缩水，授信从「安全垫」变成「赚钱能力」**：行业文章称返点大幅下调并与封户率挂钩（非官方），媒体还报道过 Meta 要求代理商垫款。长虹佳华有授信体系，但分销已占用大量营运资金，能拿多少做广告授信要先算清。
3. **Meta 是挑互补的组合**：传闻新增约 2 家（非官方），不必在店匠的强项上和它比。
4. **提前结盟**：领拓、龙商有产业带客户，但资本偏弱或待核、授信能力有限，可以变成我们的二级代理和路演证据。
5. **主打「制造 + 金融」之前先验证**：金融在 Meta 有特殊政策，制造业 B2B 获客传统上更偏 Google、LinkedIn。

## 方法要点

- **红线**：只有官方证据确认失信、破产、吊销、经营异常或重大处罚才出局；资本偏弱、诉讼、表述不实是「附条件」，在打分里扣分；未核实线索只小幅折扣。
- **检查项打分**：每维度 5 个检查项，人或模型只判断成立与否并挂证据，代码算分。核心项 3 份、一般 2 份、次要 1 份分配满分 5；数量类分档；同一事实不重复计分。
- **证据分级**：工商、上市公告、平台官方目录为 A 级；自述和媒体为 B 级；转引为 C 级，只作线索。一个维度只有 B 级证据时最高 3.5 分；长虹佳华同样适用。
- **模型编排**：便宜模型抽取并核对原文引文，强模型只判断检查项，打分、红线核查、概率由代码完成。5 家全量约 ¥4.9/次，增量重跑约 ¥2.4/次。
- **定权与校准**：按 Meta 的账定权（增量消耗 − 授信损失 − 政策风险），客户增量 30、投放运营 20、财务与合规各 15、技术与增长各 10；页面里可用两两比较法定权；标准答案集、回测数据还没建立，是 V1.5 的第一项工作。

## 边界

- 工商和司法数据本次无法直接访问：对手的减资、诉讼线索来自转引，只作「待核·有不利线索」，不据此判出局；长虹佳华同样没做工商与司法核验。
- Meta 这次的名额数和评估标准没有官方公开信息。
- 自动流程代码和测试已就绪，还没有用真实 API key 跑过；v1.1 的检查项由人工按同一规则判断。
- 页面里「上次自动重跑」是模拟数据，只演示机制。
