    方法、成本与局限

    评分框架：六个维度从哪来，Meta 的公开信号
    Meta 在看什么
      模型编排：哪一步用便宜模型，哪一步用强模型，怎么防编造
      1

      检索：每家公司 × 每个维度 1 条查询，加名单里的种子链接。用搜索 API，不用大模型。

      2

      抽取（便宜模型）：逐页读正文，只抽事实，每条必须带原文引文。程序核对引文确实出现在网页里，对不上直接丢弃。

      3

      判分（强模型）：每家公司调用一次，按评分细则打分，只能引用第 2 步留下的证据。没证据的维度强制为「未知」。

      4

      汇总（纯代码）：加权、排名、diff、提醒。不用模型，结果可复算。

      成本：

      单价是假设值（元/百万 token：便宜模型 入 1 出 4，强模型 入 20 出 80；检索 0.06 元/次），按实际供应商改 lib/score.js 的 DEFAULT_PRICING。

      合规：模型可换国产或 Azure OpenAI
      • 模型接口走 OpenAI 兼容协议，改环境变量即可切到国产模型（如 DeepSeek、通义千问），数据不出境。
      • 也支持 Azure OpenAI。长虹佳华本身分销 Azure OpenAI，这套工具可以跑在自家云资源上，顺带做成客户案例。
      • 只采集公开网页，不登录、不绕过反爬；证据保存原文链接和访问日期，便于审计。
      局限：哪些地方需要人来校准
      • 四家都是非上市民企，资金和合规大量「未知」，这两维权重最高，需要销售渠道或 Meta 渠道经理补信息。
      • 公司自述可能与事实不符，比如宜客的客户数和人员规模对不上，已降置信度。
      • 实体消歧：「领拓」有境内外两个主体，「龙商」品牌和法人不同名，新增公司时需人工确认。
      • 「微软独家技术」「微软广告核心代理」只有内部口径，没找到署名来源，未计入评分。
      • 权重还没用已知结果回测，初始值是推理得出，需业务负责人拍板。
      • v1 证据由人工按 Agent 规则整理；在线流水线已写好并有测试，但还没用真实 API key 跑过。
