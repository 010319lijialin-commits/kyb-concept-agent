# 改动说明

## v1.3（2026-10-10）：门槛改为红线核查，按 Meta 的账定权重

**问题**：资金、合规两道门槛太绝对。没有一家被判「不通过」，但未核实的转引线索（减资、诉讼）让龙商、领拓、宜客的出局概率高达 70%–87%，等于用线索把它们否决了，和「转引只当线索」的规则矛盾。这些公司在名单里，是因为它们已经在竞标；Meta 签保密协议后会自己做尽调。

**修正**：

- **只有踩红线才出局，而且要有官方来源的证据**：失信被执行人、破产清算或吊销、经营异常、重大处罚。只有非官方来源时标「待核·有不利线索」。
- **资本偏弱、诉讼、对外表述不实不是红线**：标「附条件」（Meta 会要求保证金、降低授信额度或更正），在「财务与授信」「合规与风控」里扣分。
- **各状态的不出局概率**：通过 99%、通过·待确认 97%、待定 95%、附条件 85%、待核·有不利线索 85%（原来分别是 97%、90%、85%、50%、35%）。
- **权重按 Meta 的账来定**（增量消耗 − 授信损失 − 政策风险 − 管理成本）：客户增量 25 → 30，技术与 AI 15 → 10，其余不变。
- 「资金门槛」「合规门槛」改名为「资金红线」「合规红线」；「门槛出局」改为「踩红线出局」。
- 修了飞书卡片缺「通过·待确认」中文名的问题。

**结果**：

| | 长虹佳华 | 店匠 | 龙商 | 领拓 | 宜客 |
|---|---|---|---|---|---|
| 已证实分 | 42.5 → 41 | 45.4 → 45 | 26 → 29 | 23 → 24.5 | 15 → 16 |
| 排第一 | 46% → 42% | 44% → 43% | 2% → 4% | 5% → 10% | 2% → 1% |
| 前 2 | 77% → 75% | 72% → 73% | 5% → 18% | 16% → 27% | 11% → 6% |
| 出局 | 19% → 6% | 23% → 8% | 88% → 18% | 70% → 19% | 74% → 28% |

两家仍是第一梯队，但更紧了：客户增量权重提高后，我方在这一项的短板更突出。结论从「对手门槛有问题」变成「对手只是风险没核实，要赢得靠补客户增量的证据」。最快追平路径仍是公开产业带布局。

## v1.2（2026-10-10）：检查项分值有依据

**问题**：检查项大多「成立就加 1 分」，个别 1.5、0.5 是凭判断定的。检验发现分值换种给法，长虹佳华和店匠的先后会变，所以分值不能随手定。

**修正**：

- **分值按规则定**：每个检查项按和 Meta 公开信号的关系分为核心 3 份、一般 2 份、次要 1 份，维度内按份数分配满分 5；每项写明理由。页面「调一调 → 检查项分值」可以重新分配。
- **数量类分档**：客户规模、客户案例、广告规模、研发团队、营收或融资，部分满足得一半；Agent 判断时同时给档位，不给按最低档。
- **相关项不重复计分**：客户规模和错位客户来源、自研平台和平台对接、上市和资本实力各为一组，第二项按一半计，再换算回满分 5。
- **分值的不确定性进入概率**：排名概率抽样时分值随机浮动；「结论稳不稳」新增「检查项分值换种给法，排序变不变」。
- **提醒更细**：对手某个检查项变化但维度分变化不大时，也点名是哪一项（例：领拓新增平台奖项）。
- 修了一个页面问题：手机上方法部分的架构图把整页撑宽。

**结果**：

| | 长虹佳华 | 店匠 |
|---|---|---|
| 已证实分 | 42 → 42.5 | 45 → 45.4 |
| 排第一 | 47% → 46% | 42% → 44% |
| 前 2 | 74% → 77% | 71% → 72% |
| 门槛出局 | 21% → 19% | 24% → 23% |

分值换种给法：前两名不变的比例超过 99%，长虹佳华排在店匠前面 32%。最快追平路径仍是公开产业带布局，补上这一项就能反超。

## v1.1.1（2026-10-10）：修正「出局概率为 0」

**问题**：长虹佳华的门槛出局概率显示为 0，太绝对。原因有三个逻辑错误：

1. 合规门槛对上市公司直接判「通过」，但其实只是按上市披露推断，没做工商和司法核验。这条规则只有我方受益。
2. 门槛「通过」按 100% 计，可门槛规则本身是推断的（Meta 未公开）。
3. 只查了对手的不利信息，没查我方的。

**修正**：

- 新增「通过·待确认」状态（按 90% 计），用于按间接证据推断通过、支撑证据超过 3 年、或通过但有风险信号的情况；核实通过也只按 97% 计。
- 资金门槛增加营运资金风险信号（gx2）。
- 补查我方信息（四川长虹年报问询函回复，A 级）：
  - 长虹佳华报表经营现金流 2023–2025 连续为负，应收 36.1 亿元，存货上升；公司解释为票据贴现列报口径，剔除后为正。
  - 授信回款体系有了公告证据。
  - 2026 上半年营收增长 31%、毛利率降到 2.68%。
  - 私有化已于 2026-09 失效，上市地位保留。
- 店匠的融资证据是 2022 年的，资金门槛改为「通过·待确认」。
- 概率的口径写清楚：只在名单内比较，不含 Meta 的主观判断、路演表现、名单外候选人。

**结果**：

| | 长虹佳华 | 店匠 |
|---|---|---|
| 已证实分 | 39 → 42 | 45（不变） |
| 门槛出局 | 0% → 21% | 15% → 24% |
| 前 2 概率 | 92% → 74% | 79% → 71% |

两家是同一梯队。

# v1 → v1.1（2026-10-10）

## 为什么改

收到两条反馈：有价值的信息少；分析看起来只覆盖了一家。也参考了另一份报告的思路。

## 从参考报告里采纳的

- **先核验资质，再打分**：新增资质核验表，区分「已核实 / 待核 / 不符 / 无」。
- **门槛项**：资金、合规不达标不能被别的高分拉平。
- **证据分级**：A / B / C 三级，并且规则写进了代码。
- **对我方用同一把尺子，并做敏感性分析**。
- **对标现任一代、落到路演打法**。

## 和参考报告判断不同的三处

1. **长虹佳华不是稳居第一**。把「8 分以上需 A 级证据」「证据只证明邻近能力要降分」这些规则一致地用在我方身上，长虹佳华按已证实信息落后店匠；把门槛和不确定性算进去，两家各约一半概率排第一。差距集中在「客户增量」，补一两项证据就能追平。
2. **「国企 + 上市」是入场券，不是差异化**。现任一代里已有国资控股的上市公司（省广集团），也有多家上市公司。
3. **定位图的空白要逐家核对**。现任一代里蓝标、省广、飞书深诺都做品牌和全链路服务；「制造 + 金融」作为主线有 Meta 政策和渠道偏好上的风险，要先用内部数据验证。

## 具体改了什么

| 方面 | v1 | v1.1 |
|---|---|---|
| 结论 | 只和店匠比 | 四家对手一览 + 和每家比；第一屏是结论和需要拍板的事 |
| 评分 | 每个维度直接给 0–5 分 | 每个维度 5 个检查项，判断成立与否，代码算分 |
| 风险维度 | 加权求和 | 资金、合规两道门槛，5 种状态，查不到不等于通过 |
| 证据 | 置信度高 / 中 / 低 | A / B / C 分级 + 双源印证；只有 B 级证据的维度最高 3.5 |
| 不确定性 | 未知按固定分 | 已证实分 + 上限 + 排名概率（抽样 3000 次） |
| 可执行性 | 行动建议 | 翻盘条件：补哪几项证据、权重怎么变会改变排序 |
| 新内容 | — | 三家对手新证据（信用保险保单、TikTok 官方伙伴页、注册资本等）；微软独家授权 AI 视频广告的公开来源；值不值得的账；路演情景切换 |
| 定权 | 推理给出 | 页面内两两比较法（层次分析法）+ 一致性检查；回测脚本 |

| 测试 | 11 个 | 25 个（v1.1.1：27 个；v1.2：32 个；v1.3：33 个） |
