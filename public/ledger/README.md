# 进销账

给医药销售用的进销 + 回款账本。链路：上游进货 → 转卖给下游 → 下游回款（到公司账户或个人账户）→ 扣增值税 → 从公司提现。

打开方式：`npm start` 后访问 `http://localhost:3000/ledger/`（部署后就是 `https://你的域名/ledger/`），手机上可以「添加到主屏幕」。
不调任何 AI 接口，也不需要访问码。

## 规则（都写在 `core.js` 里）

| 场景 | 怎么记 |
| --- | --- |
| 进货 | 上游、品种、数量 × 单价。成本按品种加权平均进价 |
| 销售 | 下游、品种、数量 × 单价。每笔销售 = 一笔应收 |
| 回款（合并） | 一笔到账可以核销同一个下游的多笔销售；默认按最早的先核销，可以手动改每笔分多少 |
| 回到个人账户 | 到账已经扣过增值税。按到账反推核销的含税应收：核销 = 到账 ÷ (1 − 实际税负)，差额记为已扣税 |
| 回到公司账户 | 全额到账，标「未扣税」 |
| 月度扣税 | 选一个月份，把截止那个月底、公司里所有未扣税余额扣税，标「已扣税」 |
| 从公司提现 | 输入想拿到手的钱。先用已扣税的钱（不再扣）；不够再动未扣税的钱，这部分要先扣税。提走的部分月底不会再扣一次 |

税额口径在设置里切：
- **价税分离**（默认，13%）：税 = 金额 ÷ (1+税率) × 税率，实际税负约 11.50%
- **按点扣**：税 = 金额 × 税率

## 为什么删改不会把账弄乱

只存原始单据（进货、销售、回款、扣税、提现），余额和税每次都按日期顺序重放算出来。
删掉一笔回款，后面的扣税金额自动变；要是后面的提现因此不够了，会在顶部标红提示。
公司账户按「每笔回款一个批次」记，每个批次有剩余金额和是否已扣税，提现先进先出。

## 数据

存在浏览器 `localStorage` 的 `ledger.v1` 里，换设备 / 清缓存会丢，设置页可以导出 JSON 备份、导出销售明细 CSV。

## 测试

`npm test` 跑 `test/ledger.test.js`，覆盖：合并回款核销、个人账户扣税反推、月度扣税只扣截止日前的钱、
提现先已税后未税、删单后提现余额不足提示、两种税额口径。
