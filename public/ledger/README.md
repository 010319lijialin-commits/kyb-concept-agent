# 进销账

给医药销售用的进销 + 回款账本。链路：上游进货 → 转卖给下游 → 下游回款（到公司账户或个人账户）→ 扣增值税 → 从公司提现。

## 怎么打开

**直接用（推荐）**：claude.ai 上发布好的页面 https://claude.ai/artifact/GkaFMssXvTfsCCHEFCgBTh ，手机、电脑登录 claude.ai 都能开。
账存在你 claude.ai 账号下的私有空间里，只有你自己看得到，换设备登录同一账号也在。
页面默认只有你能打开；要给别人用，在页面的分享菜单里加人，每个人看到的都是自己的那本账。

**自己部署**：`npm start` 后访问 `http://localhost:3000/ledger/`（部署后就是 `https://你的域名/ledger/`），
手机上可以「添加到主屏幕」。这种方式账只存在浏览器里，记得定期导出备份。不调任何 AI 接口，也不需要访问码。

第一次打开、账本还空着时会先放一套**示例数据**给你点着看，示例里的操作不保存；点「开始记自己的账」就切到你自己的空账本。

## 规则（都写在 `core.js` 里）

| 场景 | 怎么记 |
| --- | --- |
| 进货 | 上游、品种、数量 × 单价。成本按品种加权平均进价 |
| 销售 | 下游、品种、数量 × 售价、这批货的进价。每笔销售 = 一笔应收 |
| 回款（合并） | 一笔到账可以核销同一个下游的多笔销售；默认按最早的先核销，可以手动改每笔分多少 |
| 回到个人账户 | 到账已经扣过税。按到账和每笔销售的税负，先进先出反推核销了多少应收，差额记为已扣税 |
| 回到公司账户 | 全额到账，标「未扣税」 |
| 月度扣税 | 选一个月份，把截止那个月底、公司里所有未扣税余额扣税，标「已扣税」 |
| 从公司提现 | 输入想拿到手的钱。先用已扣税的钱（不再扣）；不够再动未扣税的钱，这部分要先扣税。提走的部分月底不会再扣一次 |

### 扣多少税

```
税 = 回款额 × 回款税点(默认 1%) + 差价 × 差价税率(默认 13%)
差价 = (售价 − 进价) × 件数

例：进价 1、售价 1.5、200 件，回款 300
    200×1.5×1% + 0.5×200×13% = 3 + 13 = 16，到手 284
```

- 每笔销售都记一个**进价**（默认填该品种的加权平均进价，可改），所以每笔销售的税负不同：
  上面这笔是 16/300 ≈ 5.33%，差价大的货税负更高。
- 合并回款时，核销到哪笔销售就按哪笔的税负算；部分回款按比例算（回一半，扣一半的税）。
- 公司账户里每笔回款记成一个批次，批次的税负 = 它核销的那些销售的加权税负。
  回款里没对上任何销售的部分，按这个下游销售的平均税负估。
- 卖亏了（售价低于进价）差价按 0 算，只扣回款税点那部分。
- 两个税率在「设置」里改，改完历史账目全部按新税率重算。

## 为什么删改不会把账弄乱

只存原始单据（进货、销售、回款、扣税、提现），余额和税每次都按日期顺序重放算出来。
删掉一笔回款，后面的扣税金额自动变；要是后面的提现因此不够了，会在顶部标红提示。
公司账户按「每笔回款一个批次」记，每个批次有剩余金额和是否已扣税，提现先进先出。

## 数据存哪（`store.js`）

| 在哪打开 | 存在哪 |
| --- | --- |
| claude.ai 页面 | 账号私有空间 `data/users/<你的id>/ledger`，本机 `localStorage` 留一份缓存 |
| 自己部署的服务 | 只存浏览器 `localStorage` 的 `ledger.v1` |

云端单个文档上限 256 KiB，整本账按块切开存：先写新块，再改指针，最后删旧块，中途断掉也不会坏。
另一台设备改了账，这边会自动刷新。设置页可以导出 JSON 备份、导出销售明细 CSV。
