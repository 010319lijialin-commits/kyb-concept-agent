# 表达练习 MVP

一个手机浏览器就能用的网页：**录音 → 转写 → 按表达结构复盘 → 记下来**。

核心不是"讲得好听"，而是解决一个具体痛点：**在真实场景里没法条件反射地调用对应的表达结构**。
所以每次复盘都强制落到结构上——该用哪个结构、你的话填进槽位后哪几格是空的、下次开口第一句固定说什么。

## 四个页面

| 页面 | 干什么 |
| --- | --- |
| 练习 | 选场景和想练的结构（也可以让 AI 判断）→ 录音 → 自动转写（可手改）→ 出复盘 |
| 记录 | 灵感 / 方法原则 / 知识点 三类随手笔记，以及全部练习历史 |
| 结构 | 10 张结构卡，按"触发信号"排版，练的是看见场景就想起槽位 |
| 分析 | 把历史记录喂给模型，找反复犯的毛病、盲点、接下来两周的训练动作 |

## 复盘会给你什么

- **目标结构 + 为什么是它**：这个场景该条件反射用哪个
- **槽位对照**：逐格显示你哪句填了、哪格是空的（引用你的原话）
- **四项评分**：结构 / 清晰 / 简洁 / 感染力
- **口头禅统计**：「然后 x6」这种
- **最该改的 1-3 处**：每处都给可以直接替换的说法
- **示范改写**：用目标结构重写你的内容，口语化，可以直接跟读
- **条件反射训练**：触发信号 + 开口第一句 + 一句口诀
- **再说一遍**：同一话题用目标结构重录，模型会对比两版的进步

## 跑起来

```bash
npm install
cp .env.example .env    # 填上 OPENAI_API_KEY
npm start               # http://localhost:3000
```

手机上打开：跟电脑连同一个 Wi-Fi，访问 `http://<电脑内网 IP>:3000`。

> ⚠️ 浏览器只在 **https 或 localhost** 下给麦克风权限。手机用 http 访问内网 IP 时录音按钮会失败，
> 这时可以直接在输入框里手打文字复盘。想在手机上真正录音，用 `npx localtunnel --port 3000`
> 或 ngrok 之类开个 https 隧道，或者部署到任意支持 Node 的平台。

## 配置

| 环境变量 | 默认 | 说明 |
| --- | --- | --- |
| `OPENAI_API_KEY` | 必填 | 只放在服务端，不会进浏览器 |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` | 换 OpenAI 兼容网关时改这里 |
| `TRANSCRIBE_MODEL` | `gpt-4o-transcribe` | 也可以用 `whisper-1` |
| `REVIEW_MODEL` | `gpt-4o` | 复盘和长期分析共用 |
| `PORT` | `3000` | |

## 数据存哪

全部在浏览器的 `localStorage`（key：`xp.sessions`、`xp.notes`），没有数据库、没有账号，
换设备或清缓存就没了。分析页有「导出全部数据」按钮存 JSON 备份。
录音本身不落盘——转写完就丢，只留文字。

## 代码结构

```
server.js       Express，三个接口：/api/transcribe /api/review /api/analyze，兼作 OpenAI 代理
structures.js   表达结构库（id / 触发信号 / 槽位 / 口诀），复盘 prompt 和结构卡共用同一份
public/         无构建的单页前端：index.html + app.js + style.css
```

要加新结构，只改 `structures.js` 一个文件，前后端会同时生效。

## 已知取舍（MVP 故意不做的）

- 没有账号和云端同步
- 没有语速 / 停顿 / 语气分析（转写只拿文字，要做得换带时间戳的接口）
- 没有跨设备的长期趋势图，分析是每次现算的
